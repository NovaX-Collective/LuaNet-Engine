# Corresponding source

Every LuaNet release that distributes a Luanti engine publishes the exact
corresponding source for that engine as a GitHub Release asset in this
repository. Each archive contains:

- the complete pinned Luanti source checkout and initialized submodules;
- the LuaNet native bridge;
- the source transformations already applied;
- build scripts and dependency pins;
- upstream and LGPL license files;
- a checksum alongside the archive.

The source remains available from this repository independently of the
proprietary LuaNet application repository. Questions or source requests can be
sent to `luanet@novaxhosting.com`.
